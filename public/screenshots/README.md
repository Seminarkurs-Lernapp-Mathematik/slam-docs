# Screenshots

Lege Screenshot-PNGs in diesem Ordner ab. Sie werden automatisch unter
`/screenshots/<dateiname>.png` ausgeliefert.

## Namensschema

- **Schüler-App:** `student-launch.png`, `student-register.png`, `student-grade.png`,
  `student-classcode.png`, `student-feed.png`, `student-hint.png`, `student-reward.png`
- **Lehrer-Plattform:** `teacher-login.png`, `teacher-verify.png`,
  `teacher-create-class.png`, `teacher-invite.png`, `teacher-seating.png`,
  `teacher-live-feed.png`, `teacher-analytics.png`

## Empfehlungen

- Format: PNG, maximal 1600 px Breite
- Sensible Daten (echte Namen, E-Mails) bitte vorher unkenntlich machen
- Dunkler Hintergrund (z. B. `#0d1117`) passt zum Starlight-Dark-Theme
